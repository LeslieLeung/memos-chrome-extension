# Memos Clipper

[English](README.md)

Memos Clipper 是一个 Chrome 扩展，用于把随手记录或正在浏览的网页，直接保存到你自己的 Memos 实例。

## 功能

- 在扩展弹窗中创建新 Memo。
- 剪藏当前网页：将页面标题和清理后的链接填入编辑器，确认后再保存。
- 继续编辑最近创建的 Memo，或随时新建一条。
- 再次打开弹窗时恢复未提交的草稿。
- 自动追加一个可选的默认标签，且不会重复添加。
- 支持 English、简体中文或跟随 Chrome 语言。

## 安装

1. 下载并解压发布包，或从源码构建扩展。
2. 在 Chrome 打开 `chrome://extensions`。
3. 开启“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择解压后的扩展目录；如果从源码构建，请选择项目中的 `dist/` 目录。
5. 如需固定显示，可在 Chrome 的扩展程序菜单中固定 **Memos Clipper**。

## 连接 Memos 实例

1. 打开 Memos Clipper，进入“设置”。
2. 填写 Memos 实例地址，例如 `https://memos.example.com`，无需添加 `/api/v1`。
3. 在 Memos 账户中创建 Access Token，并粘贴到“Access Token”。
4. 可选：设置默认标签，例如 `#inbox`。
5. 点击“保存设置”，并同意 Chrome 请求访问该 Memos 实例。

实例地址、Token、偏好设置、草稿以及最近创建 Memo 的引用只会保存在 Chrome 的本地扩展存储中。扩展只会申请访问你配置的 Memos 域名。

## 创建 Memo 与剪藏网页

从工具栏打开扩展，输入内容后点击“创建 Memo”。创建成功后，继续在同一编辑器中保存会更新该 Memo；如需另建一条，请点击“新建”。也可以按 <kbd>Ctrl</kbd>/<kbd>⌘</kbd> + <kbd>Enter</kbd> 保存。

点击“剪藏此页”会将当前网页的标题和链接填入编辑器，并移除链接中常见的追踪参数。确认或编辑内容后再保存。Chrome 内部页面及其他非网页地址无法剪藏。

你也可以在“设置”中开启“打开扩展时默认剪藏当前网页”。它只会自动填充新的空白 Memo，不会覆盖已有草稿。

## 隐私与权限

- **存储**：使用 `chrome.storage.local` 在本机保存配置和草稿。
- **当前标签页**：仅在你主动剪藏当前页面时读取页面标题和链接。
- **网站访问权限**：仅在保存设置时，为你填写的 Memos 实例申请，用于调用其 API。

请勿泄露 Access Token。扩展不会在错误详情中显示 Token，也不会将它写入应用日志。

## 遇到问题？

请先确认实例地址可在 Chrome 中访问、Access Token 有效，并且 Chrome 已授予该实例访问权限。可从扩展弹窗重新打开“设置”并修改配置。
